# FlowGorila

Web estática de entretenimiento gamer publicada con GitHub Pages.

## Funciones

- Diseño adaptable para móvil, tableta y escritorio.
- Tema claro y oscuro.
- Tres minijuegos funcionales: Flow Trivia, memoria y reacción.
- Sistema local de XP, niveles, monedas, récords, rachas y misiones.
- Recompensa diaria.
- Tienda y carrito de demostración sin pagos.
- Comentarios y reacciones guardados únicamente en el navegador.
- Notificaciones locales y controles accesibles.

## Estructura

- `index.html`: estructura y contenido.
- `styles.css`: estilos y diseño adaptable.
- `app.js`: juegos, progreso y almacenamiento local.
- `flowgorila-logo.jpeg`: imagen principal de la marca.

## Publicación

El proyecto no necesita compilación ni dependencias. GitHub Pages puede servir directamente la rama `main` desde la raíz del repositorio.

## Privacidad

No hay formularios conectados a servidores ni herramientas de seguimiento. Todo el progreso y los comentarios se almacenan en `localStorage` dentro del navegador del visitante.
